# วิธีตั้งค่า "บันทึกกลาง" ของตรงเวลา (ทำครั้งเดียว ประมาณ 10 นาที)

บันทึกกลางคือตาราง Google Sheet ที่เก็บข้อมูลของทุกรูปที่พนักงานถ่าย (**ไม่เก็บตัวรูป**) พร้อมเวลาของ Google เอง
ทำให้ตรวจย้อนหลังได้ว่ารูปไหนถ่ายจริงเมื่อไร ไม่ต้องเชื่อนาฬิกามือถือ ถ้าไม่ตั้งค่า แอปก็ใช้งานได้ตามปกติ แค่ไม่มีบันทึกกลาง

## ขั้นที่ 1 สร้างตาราง
1. เปิด https://sheets.google.com แล้วกด **+ ว่างเปล่า** (Blank)
2. ตั้งชื่อไฟล์ด้านซ้ายบน เช่น `ตรงเวลา บันทึกรูป`

## ขั้นที่ 2 ใส่โค้ด
1. ในตาราง กดเมนู **ส่วนขยาย** (Extensions) › **Apps Script**
2. จะเปิดหน้าใหม่ที่มีโค้ดเดิมอยู่ กด **เลือกทั้งหมด** (Ctrl+A หรือ ⌘+A) แล้วลบทิ้ง
3. เปิดไฟล์ `Code.gs` (ในโฟลเดอร์ apps-script) คัดลอกข้อความทั้งหมด แล้ววางลงไป
4. กดไอคอนบันทึก (💾) ด้านบน

## ขั้นที่ 3 เผยแพร่ให้แอปเรียกใช้
1. มุมขวาบนกดปุ่มสีน้ำเงิน **Deploy** (ทำให้ใช้งานได้) › **New deployment** (การทำให้ใช้งานได้รายการใหม่)
2. กดรูปเฟือง ⚙ ข้าง "Select type" แล้วเลือก **Web app**
3. กรอกดังนี้
   - Description: `ตรงเวลา`
   - Execute as (เรียกใช้ในฐานะ): **Me** (ฉัน)
   - Who has access (ผู้ที่มีสิทธิ์เข้าถึง): **Anyone** (ทุกคน)
4. กด **Deploy** ถ้า Google ขอสิทธิ์ ให้กด **Authorize access** › เลือกบัญชีของคุณ › ถ้าขึ้นว่า "Google hasn't verified this app" กด **Advanced** › **Go to ... (unsafe)** › **Allow**
   (เป็นโค้ดของคุณเอง ปลอดภัย)
5. จะได้ **Web app URL** ยาว ๆ ลงท้ายด้วย `/exec` กดคัดลอกเก็บไว้

> ทุกครั้งที่แก้โค้ด ต้องกด Deploy › **Manage deployments** › ✏️ › Version: **New version** › Deploy ลิงก์เดิมจะใช้ต่อได้

## ขั้นที่ 4 ทดสอบลิงก์
เปิดลิงก์ที่คัดลอกในเบราว์เซอร์ ต้องเห็นข้อความ `{"ok":true,"service":"trong-wela"}`

## ขั้นที่ 5 ใส่ลิงก์ในแอป (เลือกวิธีใดวิธีหนึ่ง)

**วิธี ก (แนะนำ — พนักงานไม่ต้องทำอะไรเลย)**
1. ที่ GitHub ของแอป เข้า **Settings** › **Secrets and variables** › **Actions** › แท็บ **Variables** › **New repository variable**
2. Name: `LOG_URL`  Value: ลิงก์ที่คัดลอกไว้ › **Add variable**
3. ไปแท็บ **Actions** › **Deploy to GitHub Pages** › **Run workflow** รอให้เป็นสีเขียว
   (หรือแก้ไฟล์ `src/app-config.ts` ใส่ลิงก์ในเครื่องหมายคำพูด แล้ว push)

**วิธี ข (ตั้งในมือถือเครื่องเดียว)**
1. เปิดแอปด้วยลิงก์ `https://bbeautdb-arch.github.io/trong-wela/?admin=1` (หรือกดค้างที่ป้ายชื่อ "ตรงเวลา" มุมซ้ายบนของกล้องนาน 1 วินาที)
2. วางลิงก์ในช่อง กด **ทดสอบ** ถ้าขึ้น "เชื่อมต่อได้ ✓" กด **บันทึก**

## วิธีใช้งานหลังตั้งค่า
- ทุกครั้งที่พนักงานถ่าย แอปจะส่งข้อมูลเข้าตารางเอง ถ้าไม่มีเน็ตจะเก็บไว้ในเครื่องแล้วส่งให้ทีหลัง
- คอลัมน์ **ส่งช้ากว่าเวลาถ่าย** ตัวเลขมากแปลว่าส่งทีหลัง ส่วน **ธงสังเกต** เป็นแค่ตัวช่วยประกอบการพิจารณา (เช่น ตำแหน่งกระโดด) ไม่ได้แปลว่าโกงเสมอไป
- ตรวจรูปที่ได้รับในไลน์: เปิดแอป › กดไอคอนโล่ที่มุมบนของกล้อง › **เลือกรูปที่ได้รับ** หรือ **สแกน QR ด้วยกล้อง** แอปจะบอกว่า **ตรงกัน / ไม่พบในบันทึก / ข้อมูลไม่ตรง**

## ข้อควรรู้ (พูดตรง ๆ)
- ใครมีลิงก์ Web app และรู้รหัสรูปก็ดึงข้อมูลของรูปนั้นได้ จึงไม่ควรโพสต์ลิงก์นี้ในกลุ่ม
- ระบบนี้ช่วยให้ตรวจย้อนหลังและสังเกตความผิดปกติได้ แต่ไม่สามารถรับรองได้ 100% ว่าไม่มีการปลอมตำแหน่ง
