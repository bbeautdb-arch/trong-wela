# ตรงเวลา (trong-wela)

แอปถ่ายรูปติดตราเวลา + ตำแหน่ง สำหรับพนักงานหน้างาน ใช้กล้องสดของมือถือเท่านั้น (ไม่มีการเลือกรูปจากคลัง)
แล้วแชร์รูปเข้ากลุ่มไลน์

- เว็บ: https://bbeautdb-arch.github.io/trong-wela/
- Vite + React + TypeScript, PWA (service worker ขอบเขต `/trong-wela/` เท่านั้น)
- ข้อมูลรูปเก็บในเครื่อง (IndexedDB) ไม่มีเซิร์ฟเวอร์

## คำสั่ง

```bash
npm ci
npm run dev        # พัฒนา
npm run build      # สร้างไฟล์ใน dist/
npm run preview    # เปิดดูที่ http://localhost:4173/trong-wela/
npm run icons      # สร้างไอคอนใหม่ (scripts/make-icons.mjs)
```

ทดสอบ (ต้อง `npx playwright install chromium webkit` และเปิด `npm run preview` ไว้):

```bash
node tests/e2e.mjs chromium
node tests/e2e.mjs webkit
node tests/samples.mjs   # ภาพตัวอย่างพื้นฟ้า/กลางคืน/อาหาร (ต้องมีไฟล์วิดีโอทดสอบ .y4m ตามพาธในสคริปต์)
node tests/unit.mjs      # ทดสอบ QR payload / ลายน้ำ / ธงต้องสงสัย (ใช้ node 24)
node tests/appsscript.mjs   # จำลอง Code.gs ด้วย Node vm (ไม่ใช่ Apps Script จริง)
bash tests/make-assets.sh   # สร้างวิดีโอกล้องปลอมสำหรับชุดทดสอบความปลอดภัย (ต้องมี food/concrete/sky/night.png)
node tests/security-run-watermark.mjs chromium|webkit   # QR + ลายน้ำหลังบีบอัด/ย่อ/ครอบ
node tests/security-run-flow.mjs chromium|webkit        # ตรวจรูป, บันทึกกลางจำลอง, คิวออฟไลน์, ธงต้องสงสัย
node tests/baked.mjs        # ลิงก์บันทึกกลางที่ฝังตอน build (ต้อง build ด้วย VITE_LOG_URL แล้ว preview พอร์ต 4174)
```

(WebKit ในเครื่องทดสอบเป็น WPE ไม่มีกล้องจริง จึงจำลองเฟรมกล้อง — ไม่ใช่ Safari/iPhone จริง)

## ตราบนรูป

วันที่-เวลาไทย (พ.ศ.) มีวินาที · ชื่อ · สถานที่ · งานที่ทำ · ที่อยู่ภาษาไทยจากพิกัด (OpenStreetMap Nominatim,
สำรอง BigDataCloud — ไม่มีคีย์ ไม่ได้ก็ใช้พิกัดอย่างเดียว) · พิกัด + ความแม่น · รหัสรูป 6 ตัว · รหัสตรวจ 8 ตัว ·
ข้อความ “ถ่ายผ่านตรงเวลา” วาดลงในพิกเซลของภาพด้วย canvas พร้อมลายเส้นละเอียดทั้งภาพ

รหัสตรวจ = 8 ตัวแรกของ SHA-256 ของ (พิกเซลต้นฉบับก่อนติดตรา + เวลา + พิกัด + ข้อความที่กรอก)
หน้า “ตรวจรูป” ในแอปเทียบรหัสกับรูปที่เก็บไว้ในเครื่องเท่านั้น

## กันการหลอก (เวอร์ชัน 1.1)

พนักงานยังแค่เปิดแล้วกดถ่าย ทุกอย่างด้านล่างทำเองอัตโนมัติ

1. **QR บนตรา** (มุมขวาบนของตรา) เก็บ: รหัสรูป · เวลา (UTC) · พิกัด · ความแม่น · แฮชของชื่อ/สถานที่/งาน · รหัสตรวจ 16 ตัว
   รูปแบบ `TW1|รหัส|เวลา|lat|lon|acc|FIELDS10|VERIFY16` — เป็นข้อมูลผูกกับแฮชของพิกเซลต้นฉบับ **ไม่ใช่ลายเซ็นดิจิทัล**
2. **ลายน้ำที่มองไม่เห็น** ฝังรหัสรูป 6 ตัว (40 บิต รวมเช็กซัม) ซ้ำทั่วทั้งภาพ ฝังหลังสุดทับทุกอย่าง
   - อ่านกลับได้หลังบีบ JPEG q50–q80, ย่อ 50%, ย่อ 50% + q70, ส่งผ่านขนาด 1280px q75 (ทดสอบ 4 ภาพ ทั้ง Chromium)
   - **ไม่ทน** การครอบตัด/หมุน/ตัดต่อ (หน้าตรวจจะขึ้น “อ่านได้ไม่ครบ” ไม่ใช่ “ตรงกัน”)
   - ที่พื้นเรียบมาก ๆ (ท้องฟ้าโล่ง) อาจเห็นเม็ดเกรนจางมาก ๆ ถ้าซูมดู (ความต่างเฉลี่ย ≈ 3.5 ระดับจาก 255)
3. **หน้า “ตรวจรูป”** (ปุ่มโล่ที่หน้ากล้อง และแท็บตรวจในคลังรูป): สแกน QR ด้วยกล้อง หรือเลือกรูปที่ได้รับมา
   (เลือกรูปได้เฉพาะหน้านี้ ถ่ายต้องใช้กล้องสดเท่านั้น) → แสดง ตรงกัน / ไม่พบในบันทึก / ข้อมูลไม่ตรง / อ่านได้ไม่ครบ
   โดยเทียบกับรูปในเครื่อง และบันทึกกลาง (ถ้าตั้งไว้)
4. **บันทึกกลาง (ไม่บังคับ)**: ทุกครั้งที่ถ่าย ส่งข้อมูล (ไม่มีรูป) ไป Google Apps Script → Google Sheet พร้อมเวลาเซิร์ฟเวอร์ของ Google
   ถ้าไม่มีเน็ตจะเข้าคิวใน IndexedDB แล้วส่งเองเมื่อออนไลน์ สร้างทีละขั้นตาม `apps-script/วิธีตั้งค่า.md` (โค้ดอยู่ใน `apps-script/Code.gs`)
   - ตั้งลิงก์ได้ 2 ทาง: (ก) ฝังตอน build — GitHub → Settings → Variables → ตัวแปร `LOG_URL` (workflow ส่งต่อเป็น `VITE_LOG_URL`)
     หรือใส่ใน `src/app-config.ts` (`BAKED_LOG_URL`) (ข) เจ้าของเปิด `?admin=1` หรือกดค้างที่ป้ายแบรนด์บนหน้ากล้อง ~1 วินาที แล้ววางลิงก์
   - ธงต้องสงสัย (ความแม่นคงที่ทุกครั้ง, พิกัดนิ่งผิดปกติ, ย้ายไกลเกินจริง, เวลาเครื่องคลาดจากเวลาที่ได้พิกัด, เวลาคลาด >30 วินาที,
     ย้ายไกลจากรูปก่อนหน้า) บันทึกลงชีตเท่านั้น **ไม่ขัดขวางการถ่าย**

## ข้อจำกัดที่ต้องรู้

- แอปเว็บบนมือถือไม่สามารถยืนยันได้ 100% ว่าตำแหน่งไม่ถูกปลอม (เช่น แอป Mock Location บน Android)
  แอปตรวจนาฬิกาเครื่องเทียบกับเวลาเซิร์ฟเวอร์ (คลาดเกิน 2 นาทีจะถ่ายไม่ได้) และต้องมีพิกัดสดทุกครั้ง
- QR/แฮชในรูปเพียงอย่างเดียวไม่กันคนที่ตั้งใจปลอมได้ทั้งหมด (ใครมีโค้ดแอปก็สร้าง QR ปลอมเองได้) ตัวที่ยึดได้จริงคือ
  **บันทึกกลางที่มีเวลาเซิร์ฟเวอร์ของ Google** — รูปที่ไม่มีรายการตรงกันในชีตควรสงสัยไว้ก่อน
- `doGet?code=` ของ Apps Script ตอบข้อมูลให้ทุกคนที่มีลิงก์ + รหัสรูป (ไม่มีรูป) อย่าเผยแพร่ลิงก์ให้คนนอก
- ธงตรวจ Mock Location เป็นการเดา (heuristic) ไม่ใช่การตรวจจับที่แน่นอน
- LINE บีบอัดรูปเมื่อส่ง รหัสตรวจจึงใช้เทียบกับต้นฉบับในเครื่องผู้ถ่าย ไม่ใช่ไฟล์ที่ส่งแล้ว
- เพื่อให้ลิงก์เปิดนอกเบราว์เซอร์ใน LINE ได้เลย แจกลิงก์เป็น `https://bbeautdb-arch.github.io/trong-wela/?openExternalBrowser=1`
